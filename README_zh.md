# Sephiria ModMaker

手动安装时，只需下载Release中的 **SephiriaModMaker-版本.zip**。**无需另行下载update.json，也无需将其放入安装目录。** 自动更新功能会读取该文件以检查版本并验证下载内容。在编辑器中选择更新时，ZIP也会自动下载。

- README和更新记录可在GitHub仓库查看，不包含在Release ZIP中。
- 每次启动编辑器都会检查更新。发现新版本后会打开更新窗口；关闭后仍可通过顶部提示稍后更新。关闭自动检查或跳过该版本后不会自动弹窗。

## 2.5.31 — 2026-09-21

- 为 ModMaker 界面加入了**深色主题**。可以从 `工具 ▾ → 深色界面` 直接切换，或在 `设置 → 界面主题` 中选择跟随系统／浅色／深色。默认跟随系统，更改后无需重启即可立即生效。
- 在 `设置 → ModMaker Runtime` 和 `工具 ▾` 中加入了**重启游戏**。游戏只在启动时读取模组，所以在 `安装到游戏` 之后按下它，就能立刻确认修改内容。进行中的一轮会从游戏保存的位置继续。
- 修复了触发效果**强化物品**填入负数时完全没有反应的问题。现在附魔次数可以降到0以下，物品等级会真正下降；等级低于0时该神器会被关闭。无法强化时，原因（最大等级为0・已达上限）会写入 `Player.log`。
- **服装补丁**现在可以去掉游戏角色的能力值。勾选 `用下面的列表替换原始能力值` 并清空列表，角色就没有任何能力值；也可以按 `复制原始能力值` 填入原值后，只删除想去掉的那一行。数值设为 0 只会关闭效果，该行仍会显示在角色选择画面，因此要彻底去掉请删除该行本身（例如学者蜥蜴的 `魔力环流`）。
- 加入了神器选项**绝对唯一**。整个队伍中只能存在一个；只要有人携带，它就会从所有人的奖励、商店、神秘之壶、奇迹、口袋次元与炼金候选中移除。提示中的 `[唯一效果]` 会变为 `[绝对唯一]`。
- 当游戏中安装了 **DungreedEnemies** 时，也可以使用它的怪物与资源。素材库中会出现 `[Dungreed]` 图像与动作，武器攻击音效的选择中会出现其音效，敌人修改・敌人添加列表中会出现121种怪物（18种Boss）。未安装时不会增加任何内容。

更新编辑器后，请用**安装到游戏**将附带运行时也更新至2.5.31。此版本保存的模组需要运行时2.5.31或更高版本。

## 使用资源库

从原版图鉴打开资源库并读取游戏资源。首次创建需要一些时间，无需启动游戏。可按名称、类型和源文件搜索，并预览图片、逐帧动画及声音。

保存模组后，通过图片或动作的浏览按钮选择资源，即可导入到`Assets/Library`。PNG旁的`.sprite.json`用于保留基准点和游戏内尺寸，请一起保留。也可继续从文件选择PNG、GIF或帧文件夹。声音保存为游戏事件引用，不会提取为WAV。导入动画不会复制攻击判定、事件或AI。

## 安装

1. 从 [Releases](https://github.com/Xetsumei/Sephiria-ModMaker/releases) 下载 zip，解压到任意文件夹。
2. 安装 [.NET Desktop Runtime 10](https://dotnet.microsoft.com/download/dotnet/10.0)。
3. 运行 `ModMakerEditor.exe`。

游戏文件夹会在首次启动时自动查找。找不到就在 `Preferences (设置)` 里直接指定。

仅打开编辑器不会修改游戏。按下 `安装到游戏` 时才会核对已安装的版本和附带的运行时并应用。想在启动时自动安装，可以在设置里选择。
查看状态和重新安装在 `Preferences (设置)` 的 `ModMaker Runtime`。

不需要另外的加载器。游戏自带的插件加载器会直接读取。

## 快速开始

1. `新建模组`，选一个空文件夹。会生成 `mod.json` 和 `Assets/`。
2. 在 `模组信息` 标签页填模组 ID、显示名称和作者。`新内容起始 ID` 是新内容的编号基准。生成的物品、武器和魔法的编号，排序或删除后依然保持不变。
3. 在 `物品` 标签页按 `添加`。选内部名称、种类和稀有度，再填显示文本和图标 PNG（建议 16×16 到 32×32 的像素画）。
4. 在 `常驻属性效果` 里挂属性。点击属性栏可以按 ID、名称或说明搜索。分等级的数值用逗号分隔，需要 **(最大等级 + 1) 个**。
5. 按 `校验`，再按 `安装到游戏`，然后用 `F5` 启动游戏。开新的一轮就会出现在奖励和商店里。

> 插件是在进入游戏会话时加载的，不是在标题画面。要进到大厅或一轮里才会生效。

想立刻看效果，就在 `AddOns\ModMakerRuntime\config.json` 里加上 `"testGiveItems": true`。进入一轮时每个自定义物品会各给一个。
分发之前记得改回 `false`。`制作分发包` 会自动关掉。

可以导入或替换图片和逐帧动画。新的攻击判定、AI和魔法行为仅限于各表单支持的范围，其他行为需要脚本。

## 物品

### 触发效果

把 `触发器 + 条件 + 动作` 像卡片一样叠起来。常用的组合可以用模板一次填好。

* **触发器 36 种：** 击杀 · 受击 · 命中 · 落空 · 闪避 · 翻滚 · 招架 · 反击 · 格挡成功/被破 · 复活 · 获得/失去增益或减益 · 战斗开始/结束 · 喝药水 · 打破箱子和罐子 · 消耗 MP · 获得金币 · 进入关卡 · 通关 · 每 N 秒 · 首次获得一次 · 回复 HP/MP · 每损失或回复一定量的 HP/MP · HP/MP 越过某个百分比
* **动作 26 种：** 回复 HP/MP（百分比和固定值） · 自伤 · 消耗 MP · 护盾 · 提升最大 HP/MP · 给予或扣除金币 · 给予、移除或强化物品 · 随机物品 · 重掷骰子 · 临时属性 · 永久属性（持续到本轮结束） · 施加或移除增益 · 短暂无敌 · 硬直免疫 · 发射弹丸 · 屏幕文字
* **强化物品** 会对所选物品附魔数值指定的次数（负数则取消相应次数）。附魔附在物品而不是格子上，移动后也会跟着走；与游戏的附魔一样，只对神器生效，最多到最大等级。
* **发射弹丸** 要选借用哪把武器的弹道，并设定伤害、属性、硬直和穿透次数。穿透为 1 时打中第一个目标就停下，为 0 时一直飞到寿命结束。留空则用借来的弹道原本的数值。
* **打击种类** 有基本攻击、冲刺攻击、特殊攻击、专属打击和怪物打击五种。前四种从武器借用，最后一种从怪物借用。
* **怪物打击** 先选怪物，再选该怪物的打击栏。怪物的攻击同样使用与武器一致的打击数据，可以原样发射。只有拥有可借打击的怪物才会出现在列表中，两栏都填好才会发射。装好运行时并进入一次游戏后列表才会填充。
* **条件：** 触发概率（可按等级设定） · 再次触发的冷却 · HP/MP 比例 · 仅战斗中

> 必须确实结束的效果请用 `施加增益` 而不是 `施加临时属性`。增益走游戏本身的增益系统，图标、剩余时间和层数都会显示在 UI 上。

会不断累积的神器也能只用表单做出来。

* 增益标签页的 `永久` 打开后，时间过去也不会消失。
* `施加增益` 的 `失去物品时一并移除` 在永久增益上一定要开。关掉的话反复捡起丢下就能无限叠加。
* `施加临时属性` 的 `最大累积` 可以直接写成「每次命中加 1，最多 50」。
* `施加永久属性` 的 `显示累积值` 和效果行的 `显示冷却` 打开后会用屏幕图标展示。显示用的增益由运行时自动生成。

### 发动限制

限制神器只在特定情况下生效。游戏本身只有 10 种限制，但选 `★ 自己定义` 就能按行叠加条件。**所有行同时满足**才会开启。

| 条件 | 能看什么 |
|---|---|
| 背包中的位置 | 内侧 · 边缘 · 最上/最下行 · 最左/最右 · 两端列 · 角落 |
| 指定的行 / 列 | 从上数第 N 行、从左数第 N 列 |
| 相邻格 · 周围格详情 | 上下左右、斜向、周围 8 格 × 神器 / 主动 / 魔法书 / 同伴 / 石板 / 药水 / 空格 / 任意物品 / 特定组合 / 特定物品 / 名称含指定文字的物品 |
| 整个背包 | 持有上述对象 N 个以上时 |
| 血量 · 魔力 · 持有金币 | 满 · 不满 · N% 以下 · N% 以上 |
| 自己的属性值 | 指定属性高于或低于某值时 |
| 身上的增益 | 增益和减益都算 / 只算增益 / 只算减益 |
| 层数 · 战斗中 · 本神器的等级 | 如字面 |

每行都能开 `取反`（不满足时）和 `全部`（指定的格子必须全部符合）。
按 `自动生成说明文` 会把符合当前条件的句子填进文本标签页的 `发动条件` 栏。这一行会原样出现在提示框里，也可以自己改。

打开 `不可被无视限制` 后，解除限制的石板和刻印对这个神器不起作用。

> 血量、魔力和战斗状态的条件只有在拿着物品时才能判定，所以不会反映在高亮可放位置的预览里。游戏本身的 `血量满时` 限制也一样。

游戏本来只在背包变动时才重新判定限制。所以只有条件会在战斗中变化的神器（比如看血量或属性的），运行时才每 0.25 秒单独查一次，答案变了才刷新那一个。可以用 `config.json` 的 `watchDynamicCriteria` 关掉。

### 出现条件

用和发动限制一样的条件表，决定物品会不会出现在奖励和商店里。这是在物品进背包之前问的条件，所以跟位置有关的种类不在其中。
挂上 `限定单把武器` 后，只有装备那把武器时才会出现，提示框上也会加专属标记。

### 外观装饰

和游戏里绝对之戒让武器柄发光、阿格玛投影剑在背后浮出翅膀是同一个位置。

* 可以挂在玩家身上（跳跃时一起浮起） · 站立位置（留在地面） · 武器柄 · 武器刃。
* 把 `跟随` 设成延迟跟随，就会像翅膀或披风那样被拖着走。
* 可以设定偏移（1 是 16 像素） · 大小 · 前后顺序 · 色调 · 最低强化等级 · 随朝向翻转。
* 如果挂了发动限制，还能只在满足条件时显示。

图像栏接受一张 PNG 或一个文件夹。文件夹会按名称顺序播放帧。选 GIF 的话编辑器会自动拆成 PNG 文件夹。

> 纯粹是外观装饰，和判定、伤害无关。

### 画面效果

满足条件期间加在自己屏幕上的效果，和游戏里的蓝环是同一个位置。

`叠加图像` · `画面染色` · `边缘变暗` · `饱和度` · `黑白` · `亮度` · `对比度` · `色相旋转` · `颜色反转` · `画面震动` · `缩放` · `故障效果` · `画面扭曲` · `黑屏` · `蓝环效果`

位置（全屏、两侧、上、下）、强度、淡入淡出时间、重复间隔、呼吸式闪烁都按行设定。也可以和队友共享。

### 属性转换

把某个属性的超出部分转到另一个属性上。和贝鲁特之镰把暴击率超过 100% 的部分转成处决率是同一个方式，任意属性之间都能挂。

### 属性占用

锁住一部分某属性，作为代价提升另一个属性。和渴望之珠占用 MP 换取魔法伤害是同一个位置。

占用 MP 时会直接使用游戏的占用 MP，显示为紫色条。其他属性则只是相应扣减。
给出的数值可以按等级用逗号分开写，也能设上限。提示框里的说明行由运行时按渴望之珠的语序自动生成，不用手写。

> 游戏的 300 多个属性键里，有正式名称的只有一半。占用没有名称的属性时提示框会直接打出键名，所以请在 `占用属性名称` 栏里自己填上叫法。

### 石板网格

在 7×7 网格上**左键 +1 / 右键 −1 / 中键清空**来填写。
一个格子里可以把等级和 `解除限制`（蓝）、`等级反转`（紫）叠在一起。叠加时游戏会先把等级全加起来，再应用反转。
游戏无法表达的格子（直线超过 4 格、斜向 2 格以上）是锁住的。`CHECKERBOARD` 这类特殊规则在 `高级 (文本)` 标签页里写。

### 结契神器

由 `作为结契神器生成` 的勾选决定。选了两个组合并不会自动变成结契，游戏里也有 15 个不是结契却带两个组合的物品。
稀有度和结契无关，可以自由选。结契不是替代等级的评级，而是加在等级之上的标记。勾选后会按原版惯例默认填入 `稀有`。

## 武器

武器**只能做成现有武器的派生**。行为和动作直接沿用模板武器的，只改图像、数值和名称。

> 武器列表、段数和专属打击是游戏生成的信息。要在装好运行时的状态下进过一次游戏，武器标签页的栏位才会填上。

* **模板武器** 是复制的原型，**父武器** 是会强化成这把武器的武器。父武器是 1 阶，这把就是 2 阶。直接输入时 `0` 不是空，而是剑与盾 1 阶，要清空请写 `-1`。
* **打击数值** 一段一行，行数由模板决定。基本栏是倍率、属性、硬直和击退，`高级` 里有顿帧、前冲、每点 MP 追加伤害、瞄准辅助、打击标签和伤害公式。留空的栏沿用模板的值。
* **打谁** 里选择目标（敌人或友方），也可以把伤害改成治疗，用治疗倍率决定回多少。
* **弹道图像** 会替换这一段所发射之物的贴图，基准点和旋转也一起设定。
* **弹道行为** 包括速度倍率、寿命、穿透、大小倍率、追踪和追踪力度、撞墙时的处理、弹跳次数。
* **多发射击** 可以设定连射次数和连射间隔（毫秒）。
* **命中时施加的增益和减益** 可以加在被打的一方或出手的一方身上。
* **属性** 只能选物理、火、冰、雷。其他属性没有对应的元素属性可乘，伤害会大幅下降。
* 有些武器会另外出现**武器种类专属打击**，比如火棍完全不用基本连段。改了基本连段但游戏里没变化，就看这里。
* **弩机参数** 是弹匣容量、弹匣数、装填时间和射击间隔。弩的谱系只能和弩相连。
* **图像** 是日志和铁砧用的图，以及外观贴图（本体、副手、刀刃叠加、头部）。模板没有的部位会锁住。基准点留空会沿用模板的，多数情况不用动。

`恢复为模板武器的初始值` 可以随时回到最初状态。

## 魔法

复制现有魔法，改名称、图标、各等级消耗 MP、冷却、使用次数、吟唱速度、系统和标签颜色。做好的魔法在 `魔法书` 物品的 `使用的魔法` 里选中，就会出现在游戏里。

* **沿用模板行为** 使用现有魔法的行为。飞出什么、怎么炸开，都由被复制的魔法负责。
* **增益魔法** 的行为由本工具生成。施放时回复 HP 并施加指定的增益，也可以对附近所有队友生效。MP 消耗和 MP 不足时阻止施放都由游戏处理。

> 持续回复要在增益那边做。游戏的 `HP_REGEN` 是每 10 秒的回复量，所以想在 5 秒内每秒回 4，就是持续时间 5 秒配 `HP_REGEN 40`。

## 角色（服装）

复制现有服装，修改能力值、初始物品和初始武器。做好的角色会正式出现在选择画面上。状态切换和判定框沿用被复制服装的。

## 同伴

同伴神器召唤单位后会把它转到持有者的阵营，并让持有者当队长。转阵营这件事游戏本来就在做，所以**敌方怪物也能直接当同伴。**

* **想直接用游戏里的怪物**，就把物品种类设为 `同行凭证`，在 `召唤的单位` 里选。可选的是 `原版图鉴` 的 `单位` 标签页里标了 `可作同伴` 的那些。
* **想画新同伴**，就在 `同伴` 标签页复制原版怪物，改图像、名称、血量、移动速度和体型。做好的单位同样能在神器的 `召唤的单位` 栏里选。

攻击力、复活时间和分等级的成长值在神器那边，不在单位上。

> Boss 和精英怪不能用，专属 AI 掌握着阶段和演出。
> 攻击方式和移动（AI）无法新做。`要复制的怪物` 实际上也就是在选「怎么打」。
> `体型` 是寻找召唤位置时用的数值。只把图放大而不改这个，召唤出来就会卡在墙里。

## 敌人

* **敌人调整** 会改原版敌人和 Boss 的血量倍率、伤害增幅、移动速度、体型、出招间隔和属性。目标可以写 AI 类名、预制体名或单位 ID 中的任意一种，留空则对该种类全体生效。留空的栏保持原样。数值在敌人出现时由房主一侧应用一次。
* **新增敌人** 是复制原版怪物、只改图像名称数值做出新敌人，再放到层里。替换不动层的构成和数量，最安全；加进波次里则会相应提高难度。

新做出招或改变顺序这类事，每个 Boss 的代码都不同，表单装不下。请用自定义脚本。创建脚本项目时会一并生成 `SampleEnemy.cs` 示例。

## 其他标签页

* **天赋** 是每级属性加 5/10/20 级特典。边框留空会借用原版天赋的边框并染成代表色，特典图标留空则借用同阶的图。
* **组合** 是新的物品分类和按件数生效的套装效果。
* **奇迹** 是换层时选的祝福，选定后属性会保持到本轮结束。
* **命运刻印** 是在村庄树上用蓝宝石买的解锁格。这里做的格子会接在前置刻印后面，用来解锁物品标签页里开了 `需要解锁` 的物品。蓝宝石价格用逗号分开写，就变成可以买多次的格子。
* **关键词** 是写进说明里的 `<tag=…>` 名称。给上颜色和图标后，待遇和原版关键词完全一样。和游戏里已有的名称重复时会跳过。
* **属性** 是模组自己统计的新属性名。游戏的属性就是一本带标签的数字字典，所以只要登记名称，就会像原版属性一样累积和被读取。不过游戏不会自己去用，请通过发动限制（`自己的属性值`）或属性转换把它接起来。

## 修改原版

* **物品补丁** 会改现有物品的价格、蓝宝石价格、稀有度、分类、最大等级和属性，也能替换图标、名称和风味文本。
* **组合补丁** 会重写原版组合的阶梯表。按 `载入原版数值` 填入当前的表，再在上面改。原版只有 2、3、4、5、6 件的阶梯，但这里没有数量限制，20 件的阶梯也能加。只要写了一行，就会整个取代原版的表。
* **服装补丁** 会调整现有角色的能力值、初始物品和初始武器。

改过的内容在游戏运行期间保持，要还原需要重启游戏。

## 模组专属功能

不是针对单个内容，而是**整个模组施加给原版的设置**。位于左侧列表 `模组信息` 正下方的 `模组专属功能` 分组中。

* **原版禁用** 会把勾选的原版内容变得像游戏自身的占位数据一样。数据仍留在游戏中，所以已拥有的物品和存档不会损坏，只是玩家无法再遇到它们。可用搜索和 `仅显示已禁用` 查找，也能选中多行一次性禁用或取消。
  * **物品** 不会解锁，因此不会出现在奖励、商店、神秘之壶、奇迹、图鉴和预设中。通过效果直接给予或写为初始物品的仍会照常发放。
  * **武器** 会从铁砧、训练场的强化候选、图鉴谱系和随机初始武器候选中移除。1 阶基础武器在选择武器类型时就会直接持有，因此仍会作为初始武器出现。
  * **服装** 不会出现在角色选择界面，也不会解锁。正在使用的人下次进入时会换成默认角色（进行中的轮次保持不变）。
  * **奇迹** 会从奇迹选项和图鉴中移除。若某一阶段剩下的奇迹少于 3 个，该阶段不会应用禁用。
  * **天赋** 会从天赋窗口和预设中移除，也无法投入点数。已投入的点数会保留在存档中，取消禁用后恢复。
* 多个模组填写禁用时会全部合并生效。列表使用与 `原版图鉴` 相同的数据，若为空，请在安装运行时的状态下运行一次游戏。

## 原版图鉴

为了不用进游戏对照，运行时读到的数值分六个标签页展示。搜索栏对六个标签页同时生效。

* **物品** 种类、稀有度、价格、最大等级、组合、限制、属性
* **武器** 武器系、强化阶段、父武器、段数、使用的贴图槽、本体贴图的基准点、专属打击槽、弩机参数
* **天赋** 最大等级、每级属性、5/10/20 级特典
* **组合** 水果名、使用该组合的原版物品数、各阶套装效果、是否 `可用`
* **增益** 持续时间、最大层数、赋予的属性、实现类
* **单位** 阵营、性向、AI、是否 `可作同伴`

在列表里选中一项后按 `用所选物品创建修改`，就会当场生成一条物品补丁。

> 组合的 `可用` 没有勾上的，是游戏里只登记了却没有任何物品使用、也没有效果的分类（例如 `PARTY`）。选了也不会发生任何事，所以会自动从物品标签页的选项里排除。

## 编辑器便利功能

* **列表搜索** 左侧每个列表都有搜索栏。显示名称和内部名称都能搜，韩文名称**只写首字母辅音**也能匹配（用 ㄱㅁㅅ 找到 고물상），完整字和首字母还能混着写。列表上看不到的其他语言名称同样能搜到。筛选时不会抽掉行，只是隐藏起来，所以顺序不会乱，文件夹也只在里面有匹配项时才保留。按 Esc 清空，用 ↓ 和 Enter 进入列表。
* **整理列表** 在左侧列表任意位置右键，可以插入分隔线和文件夹。放在文件夹后面并不会自动进去，只有放进文件夹里的才算。拖到最左端就会移出来。名称用 `F2` 修改。这些只是编辑器界面上的标记，对游戏没有影响，`mod.json` 里只记录摆放位置。
* **拖拽排序** 在左侧所有列表都能用。可以选中多行一起移动，也有复制按钮。
* **从其他模组导入** 会把别的模组的内容复制到当前模组，原模组不会被改动。打开带 `mod.json` 的文件夹时连触发效果一起带过来；读取已安装到游戏里的模组则只带数值、文本和结构，用 C# 代码写的行为带不过来。第二种方式需要在那个模组和运行时都装好的状态下启动过一次游戏，列表才会生成。
* **校验** 会把阻止保存的错误和参考用的警告分开提示。错误包括内部名称违规和重复、分等级数值个数不符、不存在的属性 ID。警告包括缺图标、没有效果的物品、游戏里没有的 `<tag=…>`、起始 ID 过低等。
* **多语言** 编辑器界面在 `Preferences (设置)` 里切换，保存后会自动重启。按钮名里始终留着 `Preferences`，所以切到看不懂的语言也能找回来。模组内的文本在 `模组信息` 标签页里选基准语言和额外的翻译语言。

### 游戏内的 `ModMaker 信息` 窗口

在选项画面按 `ModMaker 信息`，会显示运行时版本和已安装模组的列表。

* 点模组那一行可以启用或停用。按 `[ 应用更改 ]` 会保存后关闭游戏，下次启动生效。一轮进行中不会显示，因为会破坏存档。
* 打开 `在物品说明里显示模组名` 后，所有自定义物品的说明最下面会加上 `#模组名` 一行。这一项会立刻生效，关掉后原文也照旧保留。
* 只对使用相同模组的人显示房间的锁定始终开启，无法关闭。请看下面的[多人游戏](#多人游戏)。

## 自定义 C# 脚本

表单表达不了的行为就自己写。管道部分由 ModMaker 处理，你只要写一个类。

1. 展开 `高级 自定义脚本`，按 `打开脚本项目`。模组文件夹里会生成 `Scripts/` 项目，游戏 DLL 引用、目标框架和输出路径都已配好。
2. 写一个类。

   ```csharp
   public class BloodPact : ModMakerCharm
   {
       public override void OnCharmEffectRefreshed()
       {
           base.OnCharmEffectRefreshed();
           Log($"等级 {Level}");
       }
   }
   ```
3. 按 `构建脚本`，模组文件夹里就会生成 `Scripts.dll`。
4. 在 `自定义脚本` 栏里填上类名。

| 基类 | 用于 | 继承的游戏类 |
|---|---|---|
| `ModMakerCharm` | 物品 | `Charm_StatusInstance` |
| `ModMakerPerk` | 天赋特典 | `PassiveObject` |
| `ModMakerWeaponAddon` | 武器 | `WeaponAddon` |
| `ModMakerEnemy` | 敌人 | `MonoBehaviour` |

常驻属性、文本、图标、ID 和翻译仍然用表单里设定的值，只有行为交给代码。

直接造成伤害时请用 `DealDamage`。

```csharp
DealDamage(target, 30f, EDamageElementalType.Fire);
```

游戏会按 `DamageInstance.id` 把造成的伤害归类，显示在结算画面的伤害统计里，字符串不认识就会留成 `名称 (Unknown)`。`DealDamage` 用的是 ModMaker 为每份内容准备好的 ID，所以会按那份内容的名称和图标统计。
想按效果分开统计，就用 `ModMakerDamage.Register("MyMod_Echo", "回响")` 注册 ID，再传给 `ModMakerDamage.Deal(...)`。

> * 按一次 `构建脚本`，该模组的所有脚本都会打包进一个 `Scripts.dll`。每次按下都会把游戏 DLL 引用更新到最新，并检查表单里填的类名是否真的存在。
> * 构建需要 .NET SDK。
> * Mirror 的 `SyncVar` 需要织入，模组里加不了。状态请放在普通字段里。
> * 就算抛出异常，其余内容也能存活，但请检查 `Player.log`。
> * **分发带脚本的模组，等于让接收者运行任意代码。** 分发时请说明这一点。
> * 能用的类和名称，把游戏的 `Sephiria_Data\Managed\Assembly-CSharp.dll` 用 ILSpy 或 dnSpy 打开就能全部看到。

## 多人游戏

**只要开着模组，就只有使用相同模组的人才能在房间列表里互相看到。**

游戏没有从房间列表询问「这个人装了哪些插件」的通道。
但游戏其实**已经在用一串版本号筛选房间了。** 建房时那个值会写进 Steam 大厅信息（`HandleCreated`），房间列表**根本不会画出版本和自己不同的房间**（`HandleFound`）。用房间码直接进和 Steam 邀请也会比对同一个值，就算绕过去，连接认证（`HorayNetworkAuthenticator`）也会拒绝。

所以运行时会在版本号后面附上**已启用模组的名称和版本**。

```
1.2.3                              原版
1.2.3 +MM[mycharms v1.0.0]         开了一个模组的人
1.2.3 +MM[4#8f2c1a90]              太长时会缩成个数加指纹（筛选的作用一样）
```

这是为了从一开始就避免不知道这些自定义物品的人进来、拿到陌生的 ID 而弄坏存档。

* **模组列表必须完全一致。** 同一个模组只要版本不同，物品编号就可能错位，也就没法一起玩。读取模组的顺序无所谓，字符串总是按名称排列。
* **一个模组都没开就什么都不会附加。** 只装了运行时的人可以照常和原版玩家一起玩。
* 从 2.5.26 起此锁定始终开启，无法关闭。旧 `config.json` 里残留的 `"lockMultiplayer": false` 也会被忽略。
* 版本号除了筛选房间以外，只用于界面显示和存档里的记录栏，游戏里没有任何地方会回读这个栏位来比对。**不影响存档。**
* 如果和其他改同一处的插件一起安装，标记会附上好几个。那时**只有连那个插件也装得一模一样的人**才能看到你的房间。

## 分发

按 `制作分发包` 会做出一个接收者只需解压的 zip，里面包含以游戏文件夹为基准的路径结构和安装说明文本。

| 选项 | 内容 |
|---|---|
| **一并打包运行时** | 接收者不用另外安装运行时 |
| **打包成单一文件** | 把模组结构合并成一个 `mod.pak` 文件 |
| **加密模组** | 防止别人直接打开文件夹整个复制走 |

> 打包过的模组只有 ModMaker Runtime 0.4.0 以上才能读取。
> 加密不是完整的保护。游戏必须读得懂，所以运行时一定能解开。

**请不要自己压缩。** 把整个 `AddOns` 文件夹交出去的话，`testGiveItems` 会开着就发出去，`Mods\` 里别人的模组也会跟着走，还会带上缓存文件。`制作分发包` 会自动处理这三件事。

> **多人游戏**：一起玩的所有人都要装同一个模组。物品的网络 ID 由 `模组ID:物品名` 的哈希决定，所以同一个模组在各方都能对上。

## 疑难排查

### 模组在游戏里没出现

游戏画面上什么都不会显示，请看日志。

```
C:\Users\<用户>\AppData\LocalLow\TEAMHORAY\Sephiria\Player.log
```

按 `工具 ▾` 里的 `打开 Player.log`，就会在资源管理器中打开该文件夹并选中这个文件。

正常的话能看到这样的行。

```
[AddOnLoader] ✓ 'ModMaker Runtime' v2.5.26 by ModMaker
[ModMakerRuntime] 发现模组: My Mod v1.0.0 (物品 3 个, 补丁 0 处)
```

一行都没有就是运行时没装上。请在 `Preferences (设置)` 的 `ModMaker Runtime` 里重新安装。
有 `[AddOnLoader]` 却没有 `[ModMakerRuntime]`，说明还没进到大厅或一轮里。

### 改过的内容没有生效

游戏改了数值也要重启。怀疑是编辑器那边的话，看标题栏的 `build` 时间，可能在跑旧的副本。

### 武器标签页的栏位是空的

武器列表、段数、专属打击和弩机参数都是游戏生成的信息。在装好运行时的状态下进入一轮就会生成。刚把 ModMaker 升到新版本时也可能出现同样的提示。

### 改了武器数值但游戏里没变

有些武器种类根本不用基本连段。用自定义武器打一下，`Player.log` 里会记下实际用的是哪份数据。

```
[ModMakerRuntime] 'MyMod/MyBlade': 基本第 1 段发射, 数据 'Weapon_GreatSword_Attack1(M)-MM'
```

名字以 `-MM` 结尾就说明用的是 ModMaker 改过的值，否则就是那把武器用了自己的打击数据。不需要这些记录的话，在 `config.json` 里设 `"logWeaponAttacks": false` 关掉。

### 做好的武器在强化列表里看不到

铁砧只会从父武器的强化候选里随机显示 3 个。每把 1 阶武器有 8~10 个候选，一次没出来是正常的。用骰子重掷，或者到综合训练场确认。有没有登记成功可以在 `Player.log` 里看到。

### 属性列表很短，或者提示「未知的属性 ID」

`CRITICAL` 之类的部分属性要启动过一次游戏才会进列表。进入一轮后会生成完整列表，编辑器会保存一份副本。列表不完整期间，不会因为 ID 不认识就阻止保存。

### 编辑器弹出了错误窗口

工作内容会保留，可以继续用。详情记录在 `%TEMP%\modmaker_error.log`。

## 限制

* 可以导入或替换图片和逐帧动画。新的攻击判定、AI和魔法行为仅限于各表单支持的范围，其他行为需要脚本。
* 武器的段数改不了。打几下由动作决定。
* 弩只能从弩强化而来，也不能强化成弩以外的武器。
* 武器标签页的列表、段数、专属打击和原版图鉴，要启动过一次游戏才会填上。
* 新属性可以登记，但游戏不会自己去用。要通过发动限制或属性转换接起来才有意义。
* 自己定义的发动限制里，血量、魔力和战斗状态的条件不会反映在可放位置的预览上。
* 自定义魔法支持调整现有模板和制作增益魔法，做不了新的施法行为和弹道。
* 状态切换和判定框沿用被复制服装的。
* 攻击方式和移动沿用被复制怪物的。
* Boss 不能当同伴。
* 多人游戏里想让自定义同伴显示正常，双方都要装同一个模组。
* 标着开发中的功能还没有完成游戏内验证。
* 构建自定义脚本需要 .NET SDK，游戏更新后可能要重新构建。
* 效果文本里没有 `{VALUE}` 这类自动替换，数值请自己写。
* 内容 ID 会存进存档。物品、武器和魔法的编号会自动固定，删掉的编号也会保留占位。请一直保存好模组 ID 和游戏的 `id-map.json`。
