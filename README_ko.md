# Sephiria ModMaker

수동 설치는 Release의 **SephiriaModMaker-버전.zip만** 받으면 됩니다. **update.json은 따로 받거나 설치 폴더에 넣을 필요가 없습니다.** 자동 업데이트가 버전과 파일 검증 값을 읽는 데 사용하는 파일입니다. 편집기 안에서 자동 업데이트를 선택하면 ZIP도 직접 받을 필요가 없습니다.

- README와 업데이트 기록은 GitHub 저장소에서 확인할 수 있습니다. Release ZIP에는 포함하지 않습니다.
- 편집기를 실행할 때마다 새 판을 확인합니다. 새 판이 있으면 업데이트 창이 열리며, 나중에 하려면 창을 닫고 상단 알림줄에서 다시 선택할 수 있습니다. 자동 확인을 끄거나 해당 판을 건너뛰면 자동 창은 표시하지 않습니다.

갱신한 편집기에 포함된 런타임은 [게임에 설치]로 게임에도 적용해 주세요. 자동 업데이트가 없는 구버전은 처음 한 번 ZIP을 직접 설치해야 합니다.

코드를 쓰지 않고 세피리아 모드를 만드는 도구입니다.
편집기에서 값을 채우면 `mod.json`이 만들어지고, 게임 안에서 도는 런타임이 그것을 읽어 아이템·무기·마법·적을 실제로 만들어 냅니다.
게임에 설치하는 것도, 남에게 줄 배포본을 만드는 것도 단추 하나입니다.

## 2.3의 작업 흐름

`저장 → 검증 → 게임에 설치` 순서로 확인합니다. 게임을 띄우는 것은 `도구` 메뉴의 `게임 실행` 또는 `F5`입니다. 남에게 줄 파일은 `배포본 제작`에서 만듭니다. 초안 보관·복구와 예제 시작 메뉴는 제거했습니다.

아티팩트의 개수 제한, 게임 표시 단위에 맞춘 스탯 입력, 반전 칸 표시를 추가했습니다. 이전 `mod.json`의 스탯 값은 그대로 유지합니다. 실행 취소, 고정 콘텐츠 ID, 저장·설치 백업은 계속 지원합니다. 새 프로젝트에는 런타임 2.3.0이 필요합니다.

## 설치

1. [Releases](https://github.com/Xetsumei/Sephiria-ModMaker/releases)에서 zip을 받아 원하는 폴더에 풉니다.
2. [.NET Desktop Runtime 10](https://dotnet.microsoft.com/download/dotnet/10.0)을 설치합니다.
3. `ModMakerEditor.exe`를 실행합니다.

게임 폴더는 처음 실행할 때 자동으로 찾습니다. 못 찾으면 `Preferences (설정)`에서 직접 지정하세요.

편집기를 켜는 것만으로는 게임을 고치지 않습니다. `게임에 설치`를 누를 때 설치본과 동봉 런타임을 확인하고 적용합니다. 켤 때 자동으로 설치하게 하려면 설정에서 고르세요.
상태 확인과 다시 설치는 `Preferences (설정)`의 `ModMaker Runtime`에서 합니다.

별도의 로더는 필요 없습니다. 게임에 내장된 애드온 로더가 그대로 읽습니다.

## 빠른 시작

1. `새 모드`로 빈 폴더를 고릅니다. `mod.json`과 `Assets/`가 만들어집니다.
2. `모드 정보` 탭에서 모드 ID·표시 이름·제작자를 적습니다. `새 콘텐츠 시작 ID`는 새 콘텐츠의 번호 기준입니다. 만들어진 아이템·무기·마법의 번호는 정렬하거나 삭제해도 유지됩니다.
3. `아이템` 탭에서 `추가`를 누릅니다. 내부 이름·종류·희귀도를 고르고, 표시할 글과 아이콘 PNG(16×16에서 32×32 사이의 픽셀아트를 권합니다)를 넣습니다.
4. `상시 스탯 효과`에서 스탯을 답니다. 스탯 칸을 누르면 ID·이름·설명 어느 쪽으로도 검색됩니다. 레벨별 값은 쉼표로 적고 **(최대 레벨 + 1)개**가 필요합니다.
5. `검증`을 누른 뒤 `게임에 설치`, 그리고 `F5`로 게임을 실행합니다. 새 런을 시작하면 보상과 상점에 나옵니다.

> 애드온은 타이틀 화면이 아니라 게임 세션에 들어갈 때 로드됩니다. 로비나 런까지 들어가야 적용됩니다.

바로 보고 싶으면 `AddOns\ModMakerRuntime\config.json`에 `"testGiveItems": true`를 넣으세요. 런에 들어갈 때 커스텀 아이템이 1개씩 지급됩니다.
배포하기 전에는 `false`로 되돌리세요. `배포본 제작`은 자동으로 꺼 줍니다.

## 아이템

### 발동 효과

`트리거 + 조건 + 동작`을 카드처럼 쌓습니다. 자주 쓰는 조합은 템플릿으로 한 번에 들어갑니다.

* **트리거 36종:** 적 처치 · 피격 · 적중 · 빗나감 · 회피 · 닷지 · 패링 · 반격 · 막기 성공/파괴 · 부활 · 버프/디버프 획득·소멸 · 전투 시작/종료 · 포션 · 상자 파괴 · MP 사용 · 골드 획득 · 스테이지 입장 · 게임 클리어 · N초마다 · 최초 획득 1회 · HP/MP 회복 · HP/MP가 이만큼 닳거나 회복될 때마다 · HP/MP가 몇 % 위아래로 넘을 때
* **동작 26종:** HP·MP 회복(%·고정) · 자해 · MP 소모 · 보호막 · 최대 HP/MP 증가 · 골드 지급·소모 · 아이템 지급·제거·강화 · 무작위 아이템 · 재굴림 주사위 · 임시 스탯 · 영구 스탯(런 끝까지) · 버프 부여·제거 · 잠시 무적 · 경직 면역 · 탄환 발사 · 화면에 글 띄우기
* **탄환 발사**는 어느 무기의 투사체를 빌릴지 고르고 피해·속성·경직·관통 횟수를 정합니다. 관통은 1이면 처음 맞은 하나에서 멈추고, 0이면 수명이 다할 때까지 날아갑니다. 비우면 빌려 온 투사체의 원래 값을 씁니다.
* **타격 종류**는 기본 공격 · 대시 공격 · 특수 공격 · 전용 타격 · 몬스터 타격 다섯입니다. 앞의 넷은 무기에서 빌리고, 마지막은 몬스터에게서 빌립니다.
* **몬스터 타격**은 몬스터를 고른 뒤 그 몬스터의 타격 칸을 한 번 더 고릅니다. 몬스터도 공격을 무기와 똑같은 타격 데이터로 들고 있어서 그대로 나갑니다. 빌려 줄 타격이 있는 몬스터만 목록에 오르고, 두 칸을 다 채워야 발사됩니다. 목록은 런타임을 설치한 채로 게임에 한 번 들어가야 채워집니다.
* **조건:** 발동 확률(레벨별) · 재발동 대기시간 · HP/MP 비율 · 전투 중에만

> 지속시간이 확실히 끝나야 하는 효과는 `임시 스탯 부여` 대신 `버프 부여`를 쓰세요. 게임의 정식 버프 시스템을 타서 아이콘·남은 시간·중첩이 UI에 나옵니다.

값이 쌓이는 아티팩트도 폼만으로 만듭니다.

* 버프 탭의 `영구`를 켜면 시간이 지나도 사라지지 않습니다.
* `버프 부여`의 `아이템을 잃으면 함께 제거`는 영구 버프에 반드시 켜세요. 끄면 얻고 버리기를 되풀이해 무한히 쌓을 수 있습니다.
* `임시 스탯 부여`의 `최대 누적`으로 "적중할 때마다 1씩, 최대 50까지"를 그대로 적습니다.
* `영구 스탯 부여`의 `누적치 표시`와 효과 줄의 `쿨다운 표시`를 켜면 화면 아이콘으로 보여 줍니다. 표시용 버프는 런타임이 알아서 만듭니다.

### 발동 제약

아티팩트가 어떤 상황에서만 효과를 내도록 제한합니다. 게임이 원래 가진 제약은 10종뿐이지만, `★ 직접 만들기`를 고르면 조건을 줄 단위로 쌓을 수 있습니다. **모든 줄을 동시에 만족해야** 켜집니다.

| 조건 | 볼 수 있는 것 |
|---|---|
| 인벤토리 자리 | 안쪽 · 가장자리 · 맨 위·아래 줄 · 왼쪽·오른쪽 끝 · 양 끝 열 · 모서리 |
| 지정한 줄 / 열 | 위에서 N번째 줄, 왼쪽에서 N번째 열 |
| 옆 칸 · 주변 칸 상세 | 상하좌우·대각선·주변 8칸 × 아티팩트 / 발동형 / 마법서 / 동료 / 석판 / 포션 / 빈칸 / 아무 아이템 / 특정 콤보 / 특정 아이템 / 이름에 글자가 든 아이템 |
| 인벤토리 전체 | 위와 같은 대상을 N개 이상 가졌을 때 |
| 체력 · 마나 · 소지금 | 가득 · 가득이 아님 · N% 이하 · N% 이상 |
| 내 스탯 값 | 지정한 스탯이 얼마 이상·이하일 때 |
| 걸려 있는 버프 | 버프·디버프 아무거나 / 버프만 / 디버프만 |
| 층 · 전투 중 · 이 아티팩트의 레벨 | 그대로 |

각 줄에 `반대로`(…가 아닐 때)와 `모두`(지정한 칸이 전부 맞아야 함)를 켤 수 있습니다.
`설명 글 자동 작성`을 누르면 지금 조건에 맞는 문장이 텍스트 탭의 `발동 조건` 칸에 채워집니다. 툴팁에 그대로 나오는 줄이며 고쳐도 됩니다.

`제약 조건 무시 불가`를 켜면 제약 해제 석판이나 각인이 이 아티팩트에는 통하지 않습니다.

> 체력·마나·전투 상태 조건은 아이템을 들고 있는 동안만 판정할 수 있어, 놓을 자리를 밝혀 주는 미리보기에는 반영되지 않습니다. 게임의 `체력이 가득 찼을 때` 제약도 같습니다.

게임은 원래 인벤토리가 바뀔 때만 제약을 다시 묻습니다. 그래서 체력이나 스탯처럼 싸우는 동안 달라지는 조건을 가진 아티팩트만 런타임이 0.25초마다 따로 살펴보고, 답이 달라졌을 때 그 하나만 갱신합니다. `config.json`의 `watchDynamicCriteria`로 끌 수 있습니다.

### 등장 조건

발동 제약과 같은 조건 표로 아이템이 보상·상점에 나올지를 정합니다. 인벤토리에 들어오기 전에 묻는 조건이라 자리에 관한 종류는 빠집니다.
`무기 한 자루 제한`을 걸면 그 무기를 들었을 때만 등장하고 툴팁에 전용 표시가 붙습니다.

### 외형 장식

게임의 절대반지가 무기 자루에 빛을 두르고 아그마 투영검이 등 뒤에 날개를 띄우는 것과 같은 자리입니다.

* 붙일 곳은 플레이어 몸(점프하면 같이 뜹니다) · 선 자리(바닥에 남습니다) · 무기 자루 · 무기 날입니다.
* `따라오기`를 늦게 따라오게 두면 날개나 망토처럼 끌려옵니다.
* 어긋남(1은 16픽셀입니다) · 크기 · 앞뒤 순서 · 색조 · 최소 강화 레벨 · 방향 따라 뒤집기를 정합니다.
* 발동 제약을 걸었다면 조건을 만족하는 동안에만 보이게 할 수 있습니다.

그림 칸은 PNG 한 장 또는 폴더를 받습니다. 폴더면 이름 순서대로 프레임이 돌아갑니다. GIF를 고르면 편집기가 PNG 폴더로 뽑아 둡니다.

> 보이기만 하는 꾸밈입니다. 판정·피해와는 상관없습니다.

### 화면 효과

조건을 만족하는 동안 내 화면에 거는 효과입니다. 게임의 푸른 고리와 같은 자리입니다.

`그림 겹치기` · `화면 물들이기` · `가장자리 어둡게` · `채도` · `흑백` · `명도` · `명암 대비` · `색상 회전` · `색 반전` · `화면 진동` · `줌` · `글리치` · `화면 왜곡` · `암전` · `푸른 고리 효과`

자리(전체·양옆·위·아래), 세기, 켜짐·꺼짐 시간, 되풀이 간격, 숨 쉬듯 깜빡이기를 줄마다 정합니다. 파티원과 나눠 걸 수도 있습니다.

### 스탯 전환

한 스탯의 초과분을 다른 스탯으로 바꿉니다. 베루트의 낫이 치명타 확률 100% 초과분을 처형 확률로 돌리는 것과 같은 방식이고, 어느 스탯에서 어느 스탯으로든 걸 수 있습니다.

### 스탯 점유

한 스탯을 묶어 두고 그 대가로 다른 스탯을 올립니다. 갈망의 보주가 MP를 점유해 마법 피해를 올리는 것과 같은 자리입니다.

MP를 점유하면 게임의 점유 MP를 그대로 써서 보라색 막대로 나옵니다. 그 밖의 스탯은 그만큼 빼기만 합니다.
주는 값은 레벨별로 쉼표로 적을 수 있고, 상한도 정할 수 있습니다. 툴팁 설명 줄은 갈망의 보주와 같은 어순으로 런타임이 자동으로 붙이므로 손으로 적지 않아도 됩니다.

> 게임의 스탯 열쇠 300여 개 중 부를 이름이 붙어 있는 것은 절반뿐입니다. 이름이 없는 스탯을 점유하면 툴팁에 열쇠가 그대로 찍히므로, `점유 스탯 이름` 칸에 부를 이름을 직접 적으세요.

### 석판 격자

7×7 격자에서 **좌클릭 +1 / 우클릭 −1 / 가운데클릭 비우기**로 채웁니다.
한 칸에 레벨과 함께 `제약 해제`(파랑)와 `레벨 반전`(보라)을 겹쳐 걸 수 있습니다. 겹치면 게임이 레벨을 모두 더한 뒤 반전을 적용합니다.
게임이 표현할 수 없는 칸(직선 4칸 초과, 대각선 2칸 이상)은 잠겨 있습니다. `CHECKERBOARD` 같은 특수 규칙은 `고급 (텍스트)` 탭에서 씁니다.

### 결속 아티팩트

`결속 아티팩트로 생성` 체크로 정합니다. 콤보를 둘 골랐다고 저절로 결속이 되지는 않습니다. 게임에도 결속이 아니면서 콤보를 둘 가진 아이템이 15개 있습니다.
희귀도는 결속과 상관없이 고를 수 있습니다. 결속은 등급을 대체하는 것이 아니라 그 위에 덧붙는 표시입니다. 체크하면 바닐라 관례를 따라 `희귀`가 기본값으로 채워집니다.

## 무기

기존 무기의 **파생형으로만** 만듭니다. 동작과 모션은 템플릿 무기 것을 그대로 쓰고 그림·수치·이름만 바꿉니다.

> 무기 목록·타수·전용 타격은 게임이 만들어 주는 정보입니다. 런타임을 설치한 상태로 런에 한 번 들어가야 무기 탭의 칸들이 채워집니다.

* **템플릿 무기**는 복제할 원본이고, **부모 무기**는 이 무기로 강화되는 무기입니다. 부모가 1단이면 이 무기는 2단이 됩니다. 직접 입력할 때 `0`은 비움이 아니라 검과방패 1단이니, 비우려면 `-1`을 적으세요.
* **타격 수치**는 한 타가 한 줄이고 줄 수는 템플릿이 정합니다. 기본 칸은 배수·속성·경직·밀침이고 `고급`에 히트스톱·전진·MP당 추가 피해·조준 보정·타격 태그·피해 공식이 있습니다. 비운 칸은 템플릿 값을 그대로 씁니다.
* **누구를 때리는가**에서 때릴 대상(적·아군)을 고르고, 피해 대신 회복시킬 수도 있습니다. 회복 배수로 얼마나 회복할지 정합니다.
* **투사체 그림**은 그 타격이 쏘는 것의 그림을 갈아 끼웁니다. 기준점과 회전도 함께 정합니다.
* **투사체 움직임**은 속도 배수·수명·관통·크기 배수·유도와 유도 힘·벽에 닿았을 때의 처리·튕김 횟수입니다.
* **여러 발 쏘기**로 연사 횟수와 연사 간격(ms)을 줍니다.
* **타격 시 거는 버프·디버프**로 맞은 쪽이나 때린 쪽에 버프를 겁니다.
* **속성**은 물리·화염·얼음·번개만 고릅니다. 그 밖의 속성은 곱할 원소 스탯이 없어 피해가 크게 떨어집니다.
* **무기 종류 전용 타격**이 따로 나타나는 무기가 있습니다. 화곤봉처럼 기본 콤보를 아예 쓰지 않는 무기입니다. 기본 콤보를 고쳤는데 인게임에서 안 바뀐다면 이쪽을 보세요.
* **석궁 제원**은 탄창 용량·탄창 개수·재장전·발사 간격입니다. 석궁 계보는 석궁끼리만 이을 수 있습니다.
* **그림**은 일지·모루 이미지와 외형 스프라이트(본체·보조·칼날 덧그림·머리)입니다. 템플릿에 없는 부위는 잠깁니다. 기준점은 비우면 템플릿 것을 물려받으므로 대부분 손댈 필요가 없습니다.

`템플릿 무기 초기 값으로 되돌리기`로 언제든 처음으로 돌릴 수 있습니다.

## 마법

기존 마법을 복제해 이름·아이콘·레벨별 소모 MP·대기시간·사용 횟수·시전 속도·계통·이름표 색을 바꿉니다. 만든 마법은 `마법서` 아이템의 `사용할 마법`에서 고르면 게임에 나옵니다.

* **템플릿 동작 그대로**는 기존 마법의 동작을 씁니다. 무엇이 날아가고 어떻게 터지는지는 복제한 마법이 담당합니다.
* **버프 마법**은 동작을 이 도구가 만듭니다. 시전하면 HP를 회복시키고 지정한 버프를 겁니다. 가까이 있는 파티원 모두에게 걸 수도 있습니다. MP 소모와 MP 부족 시 차단은 게임이 알아서 합니다.

> 지속 회복은 버프 쪽에서 만듭니다. 게임의 `HP_REGEN`은 10초당 회복량이라, 5초 동안 초당 4를 회복시키려면 지속시간 5초에 `HP_REGEN 40`입니다.

## 동료

동료 아티팩트는 유닛을 소환한 뒤 주인의 진영으로 바꾸고 주인을 대장으로 삼습니다. 진영을 돌리는 일은 게임이 이미 하고 있어서 **적 몬스터도 그대로 동료가 됩니다.**

* **게임의 몬스터를 그대로 쓰려면** 아이템 종류를 `동행 증표`로 두고 `소환할 유닛`에서 고릅니다. 고를 수 있는 것은 `바닐라 사전`의 `유닛` 탭에서 `동료 가능`이 켜진 것들입니다.
* **새 동료를 그리려면** `동료` 탭에서 바닐라 몬스터를 복제해 그림·이름·체력·이동 속도·몸 크기를 바꿉니다. 만든 유닛도 아티팩트의 `소환할 유닛` 칸에서 고릅니다.

공격력·부활 시간·레벨별 성장치는 유닛이 아니라 아티팩트 쪽이 쥡니다.

> 보스와 미니보스는 쓸 수 없습니다. 전용 AI가 페이즈와 연출을 쥐고 있습니다.
> 공격 방식과 움직임(AI)은 새로 만들 수 없습니다. `복제할 몬스터`는 곧 어떻게 싸울지를 고르는 칸입니다.
> `몸 크기`는 소환할 자리를 찾을 때 쓰는 값입니다. 그림만 키우고 이 값을 안 고치면 벽에 박힌 채로 소환됩니다.

## 적

* **적 수정**은 바닐라 적과 보스의 체력 배수·피해 증가·이동 속도·덩치·패턴 간격·스탯을 고칩니다. 대상은 AI 클래스 이름·프리팹 이름·유닛 ID 중 아무거나 적고, 비우면 그 종류 전체에 걸립니다. 빈 칸은 원래대로 둡니다. 값은 적이 나올 때마다 방장 쪽에서 한 번 적용됩니다.
* **적 추가**는 바닐라 몬스터를 복제해 그림·이름·수치만 바꾼 새 적을 만들고 층에 놓습니다. 바꿔 치기는 층 구성과 마릿수를 건드리지 않아 가장 안전하고, 웨이브에 더하면 그만큼 난이도가 올라갑니다.

패턴을 새로 만들거나 순서를 바꾸는 일은 보스마다 코드가 달라 폼으로 담을 수 없습니다. 커스텀 스크립트로 하세요. 스크립트 프로젝트를 만들면 `SampleEnemy.cs` 예제가 함께 생깁니다.

## 그 밖의 탭

* **재능**은 레벨당 스탯과 레벨 5/10/20 특전입니다. 테두리를 비우면 바닐라 재능의 테두리를 빌려 대표 색으로 물들이고, 레벨 특전 아이콘을 비우면 같은 단계 그림을 빌려 씁니다.
* **콤보**는 새 아이템 카테고리와 개수별 세트 효과입니다.
* **기적**은 층을 옮길 때 고르는 축복입니다. 고른 뒤 런이 끝날 때까지 스탯이 유지됩니다.
* **운명 각인**은 마을 나무에서 사파이어로 사는 해금 칸입니다. 여기서 만든 칸은 앞 각인 뒤에 이어 붙고, 아이템 탭에서 `해금 필요`를 켠 아이템을 풀어 줍니다. 사파이어 가격을 쉼표로 적으면 여러 번 사는 칸이 됩니다.
* **키워드**는 설명에 박는 `<tag=…>` 이름입니다. 색과 아이콘을 주면 바닐라 키워드와 똑같이 다뤄집니다. 게임에 이미 있는 이름과 겹치면 건너뜁니다.
* **스탯**은 모드가 세는 새 스탯 이름입니다. 게임의 스탯은 이름표가 붙은 숫자 사전 하나라, 이름만 등록해 두면 바닐라 스탯과 똑같이 쌓이고 읽힙니다. 다만 게임이 알아서 쓰지는 않으므로 발동 제약(`내 스탯 값`)이나 스탯 전환으로 엮어 주세요.

## 바닐라 고치기

* **아이템 패치**는 기존 아이템의 가격·사파이어 가격·희귀도·카테고리·최대 레벨·스탯을 바꾸고, 아이콘·이름·플레이버 텍스트도 갈아 끼웁니다.
* **콤보 패치**는 바닐라 콤보의 단계표를 다시 씁니다. `바닐라 값 불러오기`로 현재 표를 채우고 거기서 고치세요. 바닐라는 2·3·4·5·6개 단계뿐이지만 개수 제한은 없어 20개짜리 단계도 넣을 수 있습니다. 한 줄이라도 적으면 바닐라 표를 통째로 대신합니다.
* **코스튬 패치**는 기존 캐릭터의 능력치·시작 아이템·기본 무기를 조정합니다.

고친 내용은 게임을 켜는 동안 유지되며, 되돌리려면 게임을 다시 켜야 합니다.

## 바닐라 사전

게임에 들어가 대조하지 않아도 되도록, 런타임이 읽어 온 값을 여섯 탭으로 보여 줍니다. 검색 칸은 여섯 탭에 함께 걸립니다.

> 콤보의 `쓸 수 있음`이 꺼진 것은 게임에 등록만 되어 있고 아무 아이템도 쓰지 않는 카테고리입니다(예: `PARTY`). 골라도 아무 일이 없어 아이템 탭 선택지에서 자동으로 빠집니다.

## 편집기 편의

* **목록 검색** 왼쪽 목록마다 검색 칸이 있습니다. 이름과 내부 이름 어느 쪽으로도 찾고, **초성만 적어도** 걸립니다(ㄱㅁㅅ으로 고물상). 완성된 글자와 초성을 섞어도 되고, 목록에 보이지 않는 다른 언어의 이름으로도 찾을 수 있습니다. 거를 때도 줄을 빼지 않고 감추기만 하므로 순서가 흐트러지지 않고, 폴더는 안에 걸린 줄이 있을 때만 남습니다. Esc로 지우고 ↓와 Enter로 목록으로 내려갑니다.
* **목록 정리** 왼쪽 목록 아무 곳에나 오른쪽 클릭하면 구분선과 폴더를 넣을 수 있습니다. 폴더 뒤에 있다고 저절로 들어가지 않고, 폴더 이름 밑이나 폴더 안에 놓은 것만 들어갑니다. 왼쪽 끝까지 당겨 놓으면 밖으로 나옵니다. 이름은 `F2`로 고칩니다. 편집기 화면에서만 쓰는 표시라 게임에는 영향이 없고, `mod.json`에는 놓인 자리만 적힙니다.
* **끌어서 순서 바꾸기** 왼쪽 목록 전부에서 됩니다. 여러 줄을 골라 한꺼번에 옮길 수 있고 복제 단추도 있습니다.
* **다른 모드에서 가져오기** 다른 모드의 콘텐츠를 지금 모드로 복사합니다. 원본은 바뀌지 않습니다. `mod.json`이 있는 폴더를 열면 발동 효과까지 그대로 옮겨지고, 게임에 설치된 모드를 읽으면 수치·텍스트·구성만 옮겨집니다. C# 코드로 된 동작은 옮겨지지 않습니다. 두 번째 방식은 그 모드와 런타임을 함께 설치한 상태로 게임을 한 번 실행해야 목록이 만들어집니다.
* **검증** 저장을 막는 오류와 참고용 경고를 나눠 알려 줍니다. 오류는 내부 이름 규칙 위반·중복, 레벨별 값 개수 불일치, 없는 스탯 ID입니다. 경고는 아이콘 누락, 효과 없는 아이템, 게임에 없는 `<tag=…>`, 낮은 시작 ID 등입니다.
* **다국어** 편집기 화면은 `Preferences (설정)`에서 바꿉니다. 저장하면 자동으로 다시 시작됩니다. 단추 이름에 `Preferences`가 늘 남아 있어 읽지 못하는 언어로 바꿔도 되돌아올 수 있습니다. 모드 안의 글은 `모드 정보` 탭에서 기본 언어와 추가 번역 언어를 고릅니다.

### 게임 안의 `ModMaker 정보` 창

옵션 화면의 `ModMaker 정보`를 누르면 런타임 판번호와 설치된 모드 목록이 나옵니다.

* 모드 줄을 누르면 켜고 끌 수 있습니다. `[ 변경 사항 적용 ]`을 누르면 저장한 뒤 게임이 종료되고 다음에 켤 때 반영됩니다. 런 도중에는 세이브가 깨지므로 나오지 않습니다.
* `아이템 설명에 모드 이름 표시`를 켜면 모든 커스텀 아이템 설명 맨 아래에 `#모드이름` 한 줄이 붙습니다. 이쪽은 곧바로 반영되고 꺼도 원문이 남습니다.
* `같은 모드를 쓰는 사람에게만 방 보이기`는 처음부터 켜져 있습니다. 아래 [멀티플레이](#멀티플레이)를 보세요.

## 커스텀 C# 스크립트

폼으로 안 되는 동작은 직접 씁니다. 배관은 ModMaker가 해 주므로 클래스 하나만 쓰면 됩니다.

1. `고급 커스텀 스크립트`를 펼치고 `스크립트 프로젝트 열기`를 누릅니다. 모드 폴더에 `Scripts/` 프로젝트가 만들어집니다. 게임 DLL 참조·대상 프레임워크·배포 경로가 모두 맞춰져 있습니다.
2. 클래스를 씁니다.

   ```csharp
   public class BloodPact : ModMakerCharm
   {
       public override void OnCharmEffectRefreshed()
       {
           base.OnCharmEffectRefreshed();
           Log($"레벨 {Level}");
       }
   }
   ```
3. `스크립트 빌드`를 누르면 모드 폴더에 `Scripts.dll`이 생깁니다.
4. `커스텀 스크립트` 칸에 클래스 이름을 적습니다.

| 베이스 클래스 | 쓰이는 곳 | 상속하는 게임 클래스 |
|---|---|---|
| `ModMakerCharm` | 아이템 | `Charm_StatusInstance` |
| `ModMakerPerk` | 재능 특전 | `PassiveObject` |
| `ModMakerWeaponAddon` | 무기 | `WeaponAddon` |
| `ModMakerEnemy` | 적 | `MonoBehaviour` |

상시 스탯·텍스트·아이콘·ID·번역은 폼에서 설정한 값이 그대로 쓰이고 동작만 코드가 맡습니다.

직접 피해를 줄 때는 `DealDamage`를 쓰세요.

```csharp
DealDamage(target, 30f, EDamageElementalType.Fire);
```

게임은 준 피해를 `DamageInstance.id`로 모아 결과 화면의 피해 통계에 보여 주는데, 모르는 문자열이면 `이름 (Unknown)`으로 남습니다. `DealDamage`는 ModMaker가 콘텐츠마다 만들어 둔 ID를 쓰므로 그 콘텐츠의 이름·아이콘으로 집계됩니다.
효과별로 칸을 나누고 싶으면 `ModMakerDamage.Register("MyMod_Echo", "메아리")`로 ID를 등록한 뒤 `ModMakerDamage.Deal(...)`에 넘기세요.

> * `스크립트 빌드` 한 번이면 그 모드의 스크립트가 전부 `Scripts.dll` 하나로 묶입니다. 누를 때마다 게임 DLL 참조를 최신으로 맞추고, 폼에 적은 클래스 이름이 실제로 있는지도 확인합니다.
> * 빌드에는 .NET SDK가 필요합니다.
> * Mirror의 `SyncVar`는 위빙이 필요해 모드에서 추가할 수 없습니다. 상태는 평범한 필드로 두세요.
> * 예외가 나도 나머지 콘텐츠는 살아남지만 `Player.log`를 확인하세요.
> * **스크립트가 든 모드를 배포하면 받는 사람이 임의 코드를 실행하게 됩니다.** 배포할 때 알리세요.
> * 쓸 수 있는 클래스와 이름은 게임의 `Sephiria_Data\Managed\Assembly-CSharp.dll`을 ILSpy나 dnSpy로 열면 전부 볼 수 있습니다.

## 멀티플레이

**모드를 켜 두면 같은 모드를 쓰는 사람끼리만 방 목록에 서로가 보입니다.**

게임에는 "이 사람이 어떤 애드온을 깔았는가"를 방 목록에서 물어볼 통로가 없습니다.
그런데 게임은 이미 **판 번호 하나로 방을 거르고 있습니다.** 방을 만들 때 그 값이 스팀 로비 정보에 적히고(`HandleCreated`), 방 목록은 **판 번호가 내 것과 다른 방을 아예 그리지 않습니다**(`HandleFound`). 코드로 직접 들어가는 길과 스팀 초대도 같은 값을 견주고, 그마저 뚫려도 접속 인증(`HorayNetworkAuthenticator`)이 거부합니다.

그래서 런타임은 판 번호 뒤에 **켜 둔 모드의 이름과 판번호**를 덧붙입니다.

```
1.2.3                              바닐라
1.2.3 +MM[mycharms v1.0.0]         모드 하나를 켜 둔 사람
1.2.3 +MM[4#8f2c1a90]              길면 개수와 지문으로 줄입니다 (가리는 일은 같습니다)
```

커스텀 아이템을 모르는 사람이 들어와 낯선 번호를 받고 세이브가 깨지는 일을 애초에 막는 자리입니다.

* **모드 목록이 정확히 같아야 합니다.** 같은 모드라도 판번호가 다르면 아이템 번호가 어긋날 수 있어 함께 놀 수 없습니다. 모드를 읽는 차례는 상관없습니다. 글자는 늘 이름 순으로 세워 둡니다.
* **모드를 하나도 켜 두지 않았으면 아무것도 붙지 않습니다.** 런타임만 깔아 둔 사람은 바닐라와 그대로 어울립니다.
* 게임 안 `ModMaker 정보` 창의 `같은 모드를 쓰는 사람에게만 방 보이기`(또는 `config.json`의 `"lockMultiplayer": false`)로 끌 수 있습니다. 곧바로 반영되지만, **이미 만들어 둔 방에는 만들던 순간의 판 번호가 적혀 있어** 방을 다시 만들어야 합니다.
* 판 번호는 방을 거르는 것 말고는 화면 표시와 세이브의 기록용 칸에만 쓰이고, 그 칸을 되읽어 견주는 곳은 게임에 없습니다. **세이브에는 영향이 없습니다.**
* 같은 자리를 건드리는 다른 애드온과 함께 깔면 표식이 여럿 붙습니다. 그때는 **그 애드온까지 똑같이 갖춘 사람끼리만** 방이 보입니다.

## 배포

`배포본 제작`을 누르면 받는 사람이 압축만 풀면 되는 zip이 만들어집니다. 게임 폴더 기준 경로 구조와 `설치 방법.txt`까지 들어갑니다.

| 옵션 | 내용 |
|---|---|
| **런타임 함께 넣기** | 받는 사람이 런타임을 따로 설치하지 않아도 됩니다 |
| **단일 묶음으로 배포** | 모드 구조를 `mod.pak` 파일 하나로 묶습니다 |
| **모드 암호화** | 폴더를 열어 그대로 복사하는 일까지를 막습니다 |

> 묶은 모드는 ModMaker Runtime 0.4.0 이상에서만 읽힙니다.
> 암호화는 완전한 보호가 아닙니다. 게임이 읽어야 하므로 런타임은 반드시 풀 수 있습니다.

**직접 압축하지 마세요.** `AddOns` 폴더를 통째로 주면 `testGiveItems`가 켜진 채 나가고, `Mods\` 안의 남의 모드까지 들어가고, 캐시 파일이 딸려 갑니다. `배포본 제작`은 이 셋을 자동으로 처리합니다.

> **멀티플레이**: 함께 하는 모든 사람이 같은 모드를 설치해야 합니다. 아이템의 네트워크 ID는 `모드ID:아이템이름` 해시로 정해지므로 같은 모드라면 서로 맞습니다.

## 문제 해결

### 모드가 게임에 나타나지 않습니다

게임 화면에는 아무것도 뜨지 않습니다. 로그를 보세요.

```
C:\Users\<사용자>\AppData\LocalLow\TEAMHORAY\Sephiria\Player.log
```

도구 ▾의 Player.log 열기를 누르면 그 폴더가 파일이 선택된 채로 열립니다.

정상이면 이런 줄이 보입니다.

```
[AddOnLoader] ✓ 'ModMaker Runtime' v2.3.0 by ModMaker
[ModMakerRuntime] 모드 발견: My Mod v1.0.0 (아이템 3개, 패치 0건)
```

한 줄도 없으면 런타임이 설치되지 않은 것입니다. `Preferences (설정)`의 `ModMaker Runtime`에서 다시 설치하세요.
`[AddOnLoader]`는 있는데 `[ModMakerRuntime]`이 없으면 아직 로비나 런에 들어가지 않은 것입니다.

### 고친 내용이 반영되지 않습니다

게임은 수치를 바꿔도 다시 시작해야 합니다. 편집기 쪽이 의심되면 제목 표시줄의 `build` 시각을 보세요. 옛 사본을 실행 중일 수 있습니다.

### 무기 탭의 칸이 비어 있습니다

무기 목록·타수·전용 타격·석궁 제원은 게임이 만들어 주는 정보입니다. 런타임을 설치한 상태로 런에 들어가면 만들어집니다. 새 판으로 올린 직후에도 같은 안내가 뜰 수 있습니다.

### 무기 수치를 고쳤는데 인게임에서 안 바뀝니다

기본 콤보를 아예 쓰지 않는 무기 종류가 있습니다. 커스텀 무기로 때리면 `Player.log`에 어느 값이 쓰였는지 남습니다.

```
[ModMakerRuntime] 'MyMod/MyBlade': 기본 1타 발사, 데이터 'Weapon_GreatSword_Attack1(M)-MM'
```

이름이 `-MM`으로 끝나면 ModMaker가 고친 값이 쓰인 것이고, 아니면 그 무기가 자기만의 타격 데이터를 쓴 것입니다. 이 기록이 필요 없으면 `config.json`에서 `"logWeaponAttacks": false`로 끄세요.

### 만든 무기가 강화 목록에 안 보입니다

모루는 부모의 강화 후보 중 3개만 무작위로 보여 줍니다. 1단 무기마다 후보가 8~10개라 한 번에 안 나오는 것이 정상입니다. 주사위로 다시 굴리거나 종합 훈련장에서 확인하세요. 등록 자체가 됐는지는 `Player.log`에 남습니다.

### 스탯 목록이 짧거나 "알 수 없는 스탯 ID"가 뜹니다

`CRITICAL` 같은 일부 스탯은 게임을 한 번 실행해야 목록에 들어옵니다. 런에 들어가면 전체 목록이 만들어지고 편집기가 그 사본을 보관합니다. 목록이 불완전한 동안에는 모르는 ID라는 이유로 저장을 막지 않습니다.

### 편집기에서 오류 창이 떴습니다

작업 내용은 그대로 두고 계속 쓸 수 있습니다. 자세한 내용은 `%TEMP%\modmaker_error.log`에 남습니다.

## 제한 사항

* 새 모션과 새 마법 동작은 만들 수 없습니다. 기존 것을 복제해 그림과 수치를 바꾸는 방식입니다.
* 무기의 타수는 바꿀 수 없습니다. 몇 번 때리는지는 모션이 정합니다.
* 석궁은 석궁에서만 강화될 수 있고, 석궁 외의 무기로도 강화될 수 없습니다.
* 무기 탭의 목록·타수·전용 타격과 바닐라 사전은 게임을 한 번 실행해야 채워집니다.
* 새 스탯을 등록할 수는 있지만 게임이 알아서 쓰지는 않습니다. 발동 제약이나 스탯 전환으로 엮어야 뜻이 생깁니다.
* 직접 만든 발동 제약의 체력·마나·전투 상태 조건은 놓을 자리 미리보기에 반영되지 않습니다.
* 커스텀 마법은 기존 템플릿 조정과 버프 마법까지입니다. 새 시전 동작이나 투사체는 만들 수 없습니다.
* 상태 전이와 히트박스는 복제한 코스튬 것을 씁니다.
* 공격 방식과 움직임은 복제한 몬스터 것을 씁니다.
* 보스는 동료로 삼을 수 없습니다.
* 멀티플레이에서 커스텀 동료가 제 모습으로 보이려면 양쪽이 같은 모드를 깔아야 합니다.
* 개발 중 표시가 붙은 기능은 아직 인게임 검증이 끝나지 않았습니다.
* 커스텀 스크립트를 빌드하려면 .NET SDK가 필요하고, 게임이 업데이트되면 다시 빌드해야 할 수 있습니다.
* 효과 텍스트의 `{VALUE}` 같은 자동 치환은 없습니다. 수치를 직접 적으세요.
* 콘텐츠 ID는 저장 데이터에 기록됩니다. 아이템·무기·마법 번호는 자동으로 고정되고 삭제한 번호도 예약됩니다. 모드 ID와 게임의 `id-map.json`은 계속 보존하세요.

## 일지/훈련장 비공개 (2.5.5)

아이템 상세 상단에서 **일지/훈련장 비공개**를 켜면 일지와 훈련장 목록에서 숨겨지고, 그 화면에서 꺼낼 수 없습니다. 일지 검색·즐겨찾기와 훈련장 즐겨찾기 일괄 꺼내기에도 적용됩니다. 이미 얻은 아이템은 정상적으로 사용할 수 있습니다.

보상·상점·해금·차원 주머니 규칙은 그대로입니다. 특정 아이템 효과로만 얻는 비밀 아티팩트를 만들려면 **보상 제외**도 함께 켜세요. JSON에는 `hideFromJournalAndTraining`으로 저장되며, 필드가 없는 기존 모드는 공개로 취급합니다. 사용하려면 편집기와 게임 런타임을 모두 2.5.5 이상으로 업데이트하세요.
