# Sephiria ModMaker

Windows용 세피리아 모드 제작 도구입니다. .NET Desktop Runtime 10이 설치된 PC에서 `ModMakerEditor.exe`를 실행하세요. `Runtime` 폴더를 실행 파일과 함께 보관해야 합니다.

## 시작하기

아이템의 **소원분수 비활성화**를 켜면 분수의 후보와 이전 선택에서 제외됩니다. **일지/훈련장 비공개**, **보상 제외**, **상인이 판매 금지**와 독립적으로 조합할 수 있습니다. 특정 조건에 따른 실제 지급은 아이템 효과나 스크립트로 설정하세요.

석궁의 부모는 1단에 한정되지 않습니다. 예를 들어 **대형 석궁: 화약초 연성**, **대형 석궁: 폭발 장치**의 부모로 **대형 석궁: 산탄 격발기**를 지정할 수 있습니다. 모드 석궁도 현재 템플릿을 기준으로 무기군을 판별합니다.

1. `새 모드`로 작업 폴더를 만들거나 `열기`로 기존 모드를 엽니다.
2. 왼쪽에서 콘텐츠를 골라 편집하고 `저장`을 누릅니다. 저장 단축키는 Ctrl+S입니다.
3. `검증`으로 오류를 확인합니다. 문제를 누르면 해당 편집 위치로 이동합니다.
4. `게임에 설치`로 저장한 모드와 런타임을 적용합니다.
5. `게임 실행`으로 세피리아를 시작합니다. 실행 중이라면 게임을 종료한 뒤 다시 실행하세요. 모드는 게임 세션에 들어갈 때 로드됩니다.
6. 다른 사람에게 전달할 파일은 `배포본 제작`으로 만듭니다.

우측 버튼은 `세피리아 폴더 열기 → 검증 → 게임에 설치 → 게임 실행 → 배포본 제작` 순서입니다. 설치와 실행은 각각의 버튼으로 진행합니다. 자주 쓰는 `키워드 태그 찾기`는 도구 메뉴 왼쪽에 있습니다.

게임 경로는 `Preferences (설정)`에서 바꿀 수 있습니다. 설치된 런타임의 버전이 다르면 설치할 때 두 버전을 보여 줍니다.

## 업데이트 확인

편집기를 시작할 때마다 GitHub 배포처에 새 판이 올라왔는지 확인합니다. 새 판을 찾으면 업데이트 창과 위쪽 알림줄이 나타나며, `지금 갱신`을 누를 때만 받아서 적용합니다. 저절로 바뀌지 않습니다. `이 판 건너뛰기`를 누르면 그 판에 대해서만 조용히 있고, 다음 판이 나오면 다시 알립니다. 직접 확인하려면 `도구 → 업데이트 확인`을 누르세요.

받은 파일은 배포자의 서명과 해시를 확인한 뒤에만 적용합니다. 확인에 실패하면 아무것도 바꾸지 않습니다. 갈아 끼우는 것은 편집기 파일뿐이며, 만들던 모드와 설정은 건드리지 않습니다. 갱신하면 편집기가 다시 시작되고, 저장하지 않은 내용이 있으면 먼저 묻습니다.

갱신한 뒤에는 **게임 쪽 런타임도 함께 올려야 합니다.** 다시 시작한 편집기가 설치된 런타임의 판이 다르다고 알리면 `게임에 설치`나 `Preferences (설정) → ModMaker Runtime → 지금 설치 / 다시 설치`를 누르세요.

확인이 필요 없으면 `Preferences (설정) → 업데이트`에서 끌 수 있습니다. 편집기를 `Program Files`처럼 쓰기 권한이 없는 곳에 두었다면 자동으로 갈아 끼울 수 없으므로, 배포처를 열어 직접 덮어쓰도록 안내합니다.

## 게임 사전의 언어

콤보·스탯·아이템·무기·코스튬 이름과 설명은 편집기에서 고른 언어로 표시합니다. 이름만 바뀌며 모드에 저장되는 ID와 수치는 유지됩니다. 스탯은 ID나 다른 언어의 이름으로도 검색할 수 있습니다.

이전 덤프를 쓰고 있다면 `Preferences (설정) → ModMaker Runtime → 지금 설치 / 다시 설치`로 동봉된 런타임을 적용하세요. 게임을 다시 실행해 로비/런에 한 번 진입한 뒤 편집기의 바닐라 사전을 새로 읽으면 새 번역 데이터가 반영됩니다. 언어마다 게임을 다시 실행할 필요는 없습니다. 번역이 없는 항목은 영어 또는 이전 덤프의 문구로 표시합니다.

## 저장과 실행 취소

정상 저장은 이전 파일을 `mod.json.bak`에 남깁니다. 입력 오류가 있으면 저장을 중단하고 오류 위치를 안내합니다. 기존 파일은 바뀌지 않으며, 오류를 수정한 뒤 다시 저장할 수 있습니다.

Ctrl+Z / Ctrl+Y로 편집 내용을 최대 50단계까지 취소하거나 다시 실행합니다. 실행 취소 기록은 프로그램을 닫으면 사라집니다. 외부 이미지·스크립트 수정과 게임 설치는 실행 취소 대상이 아닙니다. 자동 저장·초안 보관·초안 복구 기능은 없습니다.

## 아티팩트 개수 제한

일반 아티팩트에서 `개수 제한`을 켜고 1~999개를 입력합니다. `고유 효과`와 `개수 제한`은 동시에 켤 수 없습니다. 둘 다 끄면 기존의 일반 아티팩트처럼 동작합니다. 발동형 아티팩트와 마법서는 기존 고유 규칙을 사용합니다.

런타임 2.3은 주 인벤토리의 보유 개수를 세어 제한을 넘는 획득을 사전에 거부합니다. 획득한 뒤 아이템을 파괴하는 방식은 사용하지 않습니다. 보유한 각 아티팩트의 효과는 한도까지 중첩됩니다. 보조 가방은 게임의 고유 아이템 규칙처럼 별도로 취급하며, 주 인벤토리로 옮길 때 다시 검사합니다.

한도에 도달하면 보상 후보에서 빠지고, 버리거나 판매해 여유가 생기면 다시 후보가 됩니다. 상점 진열에는 남지만 추가 구매는 제한됩니다. JSON에는 `maxCopies`로 저장하며, 필드가 없거나 0이면 기존 동작을 유지합니다.

## 스탯 입력 단위

아이템의 상시 스탯과 발동 효과의 임시·영구 스탯 입력은 게임에 표시되는 단위를 사용합니다. JSON과 런타임의 내부 수치는 그대로 유지됩니다.

| 스탯 | 편집기 입력 | JSON 저장 값 |
|---|---:|---:|
| 치명타 확률 | 7 | 700 |
| 치명타 확률 | 0.7 | 70 |
| 근접 무기 범위 | 5 | 5 |
| 회피 무적 시간 보너스 | 0.125초 | 125 |

레벨별 값도 같은 규칙으로 변환합니다. 기존 `700`을 불러오면 `7`로 표시하며, 수정하지 않고 저장하면 `700`이 유지됩니다. 소수점은 `.`을 사용하세요.

각 스탯의 `입력 단위`에 최소 간격을 표시합니다. 게임 내부 값이 정수이므로 치명타 확률은 0.01% 단위까지 입력할 수 있지만, 근접 무기 범위는 1% 단위입니다. 지원하지 않는 자릿수는 임의로 반올림하지 않고 저장 오류로 안내합니다. `표로 편집`의 자동 채우기는 해당 간격에 맞춰 값을 생성합니다.

스탯 전환의 배수, 피해 수식, 고급 스탯 전환·점유의 내부 스탯 키 입력은 기존 형식을 사용합니다. 모드가 정의한 별도 스탯은 원래 단위를 유지합니다.

## 석판과 개발 중 기능

반전이 적용된 인벤토리 칸은 우측 상단에 `반전`을 표시합니다. 기존의 레벨 표시와 별도로 보입니다. 칸의 반전이 해제되면 표시도 사라집니다.

칸별 고유화·고유해제는 이번 버전에 포함하지 않았습니다. 고유 효과 등록과 획득 판정이 인벤토리 전체를 공유하므로, 이동·교환·멀티플레이까지 검증한 뒤 추가해야 합니다.

운명 각인, 마법, 적 추가, 코스튬, 동료와 기존 콘텐츠 수정의 모든 화면에는 개발 중 안내를 표시합니다. `바닐라 패치`의 이름은 `아이템 패치`로 바뀌었습니다.

## 설치 백업과 호환성

설치는 새 폴더에서 파일을 준비하고 확인한 뒤 교체합니다. 이전 모드는 `Mods/.modmaker-backups/모드ID/`, 이전 런타임은 `AddOns/.modmaker-backups/ModMakerRuntime/`에 보관합니다. `도구 → 설치 백업 열기`에서 확인할 수 있습니다.

이 버전에서 저장한 프로젝트는 형식 2와 최소 런타임 2.3.0을 사용합니다. 기존 콘텐츠 ID와 스탯의 내부 수치를 유지합니다. `AddOns/ModMakerRuntime/id-map.json`에는 충돌로 변경한 ID가 저장되므로 모드 구성과 함께 보존하세요.

`도구 → 게임 진단 기록`은 최근 세션의 파일 구성과 로드 결과를 보여 줍니다. 실제 전투나 멀티플레이의 모든 동작을 검증하는 기록은 아닙니다.

## 일지/훈련장 비공개 (2.5.5)

아이템 상세 상단에서 **일지/훈련장 비공개**를 켜면 일지와 훈련장 목록에서 숨겨지고, 그 화면에서 꺼낼 수 없습니다. 일지 검색·즐겨찾기와 훈련장 즐겨찾기 일괄 꺼내기에도 적용됩니다. 이미 얻은 아이템은 정상적으로 사용할 수 있습니다.

보상·상점·해금·차원 주머니 규칙은 그대로입니다. 특정 아이템 효과로만 얻는 비밀 아티팩트를 만들려면 **보상 제외**도 함께 켜세요. JSON에는 `hideFromJournalAndTraining`으로 저장되며, 필드가 없는 기존 모드는 공개로 취급합니다. 사용하려면 편집기와 게임 런타임을 모두 2.5.5 이상으로 업데이트하세요.
